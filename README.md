# Thư viện Chẩn đoán hình ảnh (mở)

Học liệu CĐHA từ nguồn mở, Việt hóa 100%. Hub tra cứu: `index.html` → publish GitHub Pages tại `rad.matcauvong.com`.

## Cách dùng
- Mở `index.html` (sau này là https://rad.matcauvong.com) → tìm theo 4 chiều: Mẫu hình+Vị trí, Phân độ & điểm, Giải phẫu & biến thể, Protocol & tổn thương tình cờ.
- Mỗi bài: `NNN-slug/lesson.md` (khung 6 mục) + `sources.md` (link gốc) + `images/` (ghi nguồn + giấy phép).
