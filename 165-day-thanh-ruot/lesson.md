# 165 — Dày thành ống tiêu hóa: Crohn vs K đại-trực tràng / Wall thickening

**Tags:** `pattern:day-thanh-ruot` `vung:ruot`
**Mức chắc chắn (certainty):** tổng hợp y văn (literature synthesis) — nhóm tự biên từ y văn mở, chưa gắn ca nguyên văn đơn lẻ.

## 1. Tổng quan — đối xứng + đoạn dài + lớp vs lệch tâm + ngắn + mất lớp

- **Crohn (viêm):** dày **đối xứng + đoạn dài** + giữ cấu trúc lớp (mục tiêu/target) + nhảy cóc (skip) + biến chứng (rò, áp-xe, hẹp).
- **K đại-trực tràng:** dày **lệch tâm + đoạn ngắn (< 5 cm)** + **mất lớp + bờ vai (shouldering)** + hạch + di căn gan.
- TẠI SAO lớp quyết định: viêm phù dưới niêm mạc giữ lớp; u xâm lấn phá lớp.
- Ngưỡng: thành ruột non bình thường ≤ 3 mm (xẹp), đại tràng ≤ 5 mm (căng); hạch ≥ 10 mm ngắn trục.

## 2. Gamut dày thành

- **Crohn:** hồi tràng + skip + rò/áp-xe + trẻ — MR enterography + sinh thiết.
- **Viêm loét đại tràng:** trực tràng lên liên tục + mất haustra (chì) — soi + mô bệnh.
- **K đại-trực tràng:** apple-core + vai + hạch + gan — CEA + mổ/soi.
- **Thiếu máu/viêm nhiễm:** đoạn dài + phù + bối cảnh (kháng sinh/C. diff) — nội khoa.

## 3. Bảng so sánh

| Thực thể (entity) | Hình ảnh | Chốt | Xử trí |
|---|---|---|---|
| Crohn | **Đối xứng + dài + giữ lớp + skip + rò** | Trẻ + hồi tràng + biến chứng | Sinh học + dinh dưỡng + mổ biến chứng |
| K đại-trực tràng | **Lệch tâm + ngắn + mất lớp + vai + hạch** | Apple-core + hạch + gan | CEA + mổ + hóa trị |
| Viêm nhiễm | Phù lan + bối cảnh nhiễm trùng | Kháng sinh + cấy | Nội khoa |

## 4. Protocol

- **CT/MR enterography** (căng ruột + MPR) khi Crohn; CT cửa + CEA khi nghi K.
- Soi đại tràng + sinh thiết là vàng (hình ảnh không thay mô bệnh).

## 5. Cạm bẫy

- **Ruột xẹp** giả dày thành — căng ruột + so sánh đoạn kề.
- **Crohn lâu năm** xơ hẹp giả u — lớp + tiền sử + mô bệnh phân biệt.
- **Viêm túi thừa** dày đoạn dài giữ lớp giả Crohn — túi thừa + tuổi già phân biệt (bài 160).

## 6. Tự lượng giá — Blind Quiz

**Ca 1 — Dày lệch tâm 4 cm + mất lớp + vai + hạch + gan nốt:** viêm hay K? *(Bảng mục 3.)*

<details><summary><b>Bấm để hiện đáp án</b></summary>

- **K đại-trực tràng:** CEA + mổ + hóa trị (không phải Crohn).
</details>

**Ca 2 — Trẻ + dày đối xứng hồi tràng + skip + rò:** chẩn đoán + thuốc đầu? *(Bảng mục 3.)*

<details><summary><b>Bấm để hiện đáp án</b></summary>

- **Crohn:** sinh học + dinh dưỡng (không mổ cắt rộng như K).
</details>
